# Интеграция Furfar и актуального бэкенда

Рабочая ветка: `IDKWht2do2`. Основа API/worker — `9dfb151`, последняя версия
`IDKWht2do` с реальными DR1-спектрами. Исходники backend, тесты backend,
API client, uv.lock и скрипты сохранены из этой версии без изменений.

Интерфейс взят из локальной папки Furfar: монохромный Astral Horizon,
процедурный звёздный фон, первый экран с прокруткой к каталогу режимов,
минимальная шапка и элементы управления гипотетической орбитой в Comparator.
В предоставленной папке есть дополнительный вложенный каталог с тем же именем;
корень проекта определяется наличием README.md, pyproject.toml и frontend/package.json.

## Согласование

- Сохранены отмена старых запросов/опроса, координаты завершённого поиска,
  источник NEOSSat при переходах, FOV/детектор в ссылках и предупреждения качества.
- В новый Spectral Lab подключён измеренный профиль DR1 с 102 номинальными слоями,
  NHITS/FLAGS и JSON/CSV. Справочные модели остаются отдельным блоком.
- Comparator сохраняет новые элементы Furfar вместе с проверкой пары, направления
  разности, FOV и выбором детектора до ограничения архивной выборки.
- Исправлено исчезновение заголовка и кнопки первого экрана при reduced motion:
  отключение анимации больше не оставляет opacity=0.
- Astral Horizon явно обозначен иллюстрацией. Он не является ICRS-картой,
  наблюдательным изображением или прогнозом координат Planet X.
- Подписи каталога режимов согласованы с реализованными возможностями;
  измерения собственного движения и атмосферная классификация не заявляются.

## Проверки

- Ruff check/format: пройдены; 61 тест backend и offline smoke четырёх операций пройдены.
- TypeScript/Vite build, 28 frontend-тестов и oxlint: пройдены.
- OpenAPI экспортирован, API client перегенерирован и проверен; контракт совпадает с 9dfb151.
- В браузере проверены новый первый экран, каталог навигации, переход в Explorer,
  реальный поиск D4 и получение cutout через API/worker, reduced motion и ширина 390 px.
- Через новый интерфейс также созданы реальный blink выбранной хронологической пары
  и DR1-профиль: 102 номинальных канала, 100 пригодных для WISE 0855; проверены график
  и мобильная компоновка. Ошибок JavaScript в успешно завершённой проверке нет.
- Реальная доступность IRSA проверяется отдельно от offline CI. Одно обращение
  к архиву при загрузке blink завершилось сетевой/архивной ошибкой; интерфейс
  показал её без подстановки синтетического результата.

Результаты браузерной проверки и резервная копия исходных объединяемых файлов
находятся локально в игнорируемом data/. FITS, .env, окружения и node_modules
в коммит не включаются. Научные ограничения — в spectra.md и roadmap.md.
