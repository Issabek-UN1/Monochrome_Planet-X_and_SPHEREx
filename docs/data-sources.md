## Источники, атрибуция и условия использования

SPHEREx — проект JPL и Caltech с финансированием NASA. На странице
[IRSA SPHEREx, Acknowledgement](https://irsa.ipac.caltech.edu/Missions/spherex.html)
размещена официальная формулировка благодарности для публикаций с этими данными;
её необходимо использовать в материалах проекта, когда применимо.
Не следует описывать проект команды как одобренный NASA.

Перед копированием чужого кода или подключением дополнительного каталога проверяются
лицензия, условия доступа, атрибуция и ограничения конкретного сайта. Доступность ссылки
не означает разрешения на произвольное повторное использование. Код WiseView и tutorial
репозиториев в наш проект не копировался.

## Обязательные тестовые поля

`GET /api/v1/targets` возвращает пять полей из Objectives: Barnard's Star,
Epsilon Indi B, WISE 0855, RW Aurigae и R Draconis. Для WISE 0855 используются
координаты из присланного условия, переведённые из часов/минут/секунд в градусы.
Остальные центры сверены через [CDS Sesame/SIMBAD](https://cds.unistra.fr/cgi-bin/nph-sesame),
ссылки на конкретные объекты доступны в `coordinate_source`.

Это фиксированные центры полей, а не вычисленные положения объекта на каждую дату.
Поиск с радиусом 0.15° и поле 0.3° оставляют запас для собственного движения;
необходимо отдельно учитывать эпоху координат, параллакс и proper motion при идентификации.
`scripts/verify_targets.py` ищет реальные наблюдения и пробует построить blink для двух
кадров одного детектора, разделённых минимум сутками. Отчёт и результаты сохраняются
в `data/target-validation`. Проверка ограниченной выборки не доказывает обнаружение
объекта, движение или изменение его яркости. Нужна визуальная/научная валидация.

## Официальные документы архива

- [SPHEREx Data Releases](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-releases/):
  DR1 охватывает первые два обзора; QR3 — следующие. Текущая конфигурация ищет обе коллекции.
- [SPHEREx Data Access](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-access/):
  SIA2 discovery, `access_url`, сервис вырезок через `center` и `size`.
  Коллекции и релизы задаются конфигурацией, не пользовательским URL.
- [IRSA SIA2](https://irsa.ipac.caltech.edu/ibe/sia.html): координаты POS в ICRS-градусах,
  TIME в MJD, BAND в метрах, MAXREC и CSV-ответы.
- [SPHEREx Data Products](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/):
  IMAGE, FLAGS, VARIANCE, ZODI; шесть диапазонов детекторов.
  WCS-WAVE предназначен для визуализации, CWAVE/CBAND — для научных измерений.
- [IRSA spectrophotometry](https://irsa.ipac.caltech.edu/onlinehelp/spherex/spherex/sp.html):
  source-mask bit 21 сам по себе не означает плохое состояние измерения; остальные
  флаги в MVP по умолчанию отклоняются консервативно.

## Результат live-проверки при подготовке

Поиск SIA2 около RA=127.69444°, Dec=−39.17760° вернул пять записей (запрошенный лимит).
Загружена реальная вырезка DR1 размером 3 954 240 байт с HDU IMAGE, FLAGS, VARIANCE,
ZODI, EPSF и WCS-WAVE; преобразование в 64×64 дало 1053 пригодных пикселя с маской по умолчанию.
Один из предварительных запросов вернул HTTP 503; последующая проверка прошла.
Эта проверка подтверждает совместимость адаптера с одним реальным продуктом,
но не гарантирует доступность всего архива или всех релизов.

Последующий прогон пяти полей из Objectives (14 ноября 2026):

| Поле | Результат в ограниченной выборке |
| --- | --- |
| Barnard's Star | Blink создан; интервал выбранных кадров ≈365.77 суток |
| Epsilon Indi B | Blink не создан: выбранные запросы вырезок вернули HTTP 503 |
| WISE 0855 | Blink не создан: выбранные запросы вырезок вернули HTTP 503 |
| RW Aurigae | Blink создан; интервал выбранных кадров ≈5.03 суток |
| R Draconis | Blink не создан: выбранные запросы вырезок вернули HTTP 503 |

Все пять запросов поиска вернули наблюдения; выборки ограничены MAXREC=100.
Это частичная проверка интеграции: подтверждены два успешных пути обработки,
но идентификация целевых источников и воспроизведение их движения/переменности ещё не выполнены.
Ошибки запросов не означают отсутствия данных или объекта. Машинный отчёт и производные
изображения находятся локально в `data/target-validation`, вне Git.

В репозитории нет скопированных научных данных. `scripts/verify_irsa.py` позволяет
повторить live-проверку самостоятельно; её результат зависит от архива.
