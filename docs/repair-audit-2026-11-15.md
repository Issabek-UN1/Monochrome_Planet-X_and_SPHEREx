Рабочая ветка: `IDKWht2do`, база `aa666c7`. Родительский checkout не изменялся.
Файлы `chat-context-handoff.md` и `spherex_chatgpt_sol_6_1.md` использованы как

## Подтверждённые исправления

| Область | Проблема | Исправление |
| --- | --- | --- |
| Опрос задач | Отмена поиска/отправки не отменяла отдельный HTTP-запрос опроса немедленно | Отдельный AbortController опроса; синхронная отмена при reset/load/run; регрессионные тесты позднего ответа |
| Источник и цель | NEOSSat мог сбрасываться при быстром выборе другой цели; повторный клик источника сбрасывал результаты | Источник хранится в App; повторный выбор текущего источника ничего не сбрасывает |
| Ручной поиск | RA/Dec формы расходились с общим полем, URL и Comparator | Выполненный поиск обновляет общее поле и ссылку; параметры задачи берутся из завершённого поиска |
| Навигация | Back/Forward сбрасывал pipeline даже при смене только режима | Сброс выполняется при смене поля/источника/параметров; режим сохраняет задачу |
| Ссылки | FOV и детектор не восстанавливались из URL | Поддержаны fov/radius/source/band; невалидные значения не попадают в форму |
| Выбор детектора | Фильтр таблицы выбирал детектор после MAXREC общей выборки | Добавлен SkySearch.detector и архивный фильтр; независимый Display detector оставлен для таблицы |
| SIA и диапазоны | Реальные em_min/em_max соседних детекторов перекрываются | Для выбора детектора используется внутренняя длина волны, затем проверяется номер файла и пользовательские ограничения волн |
| Полнота поиска | Дедупликация могла скрыть достижение MAXREC | possibly_truncated учитывает исходное число строк, включая исключённые |
| Вырезки IRSA | Единицы center не были явными | Суффикс d задаёт градусы по документированному формату сервиса |
| FITS из другого origin | Политика CORS не разрешала заголовок Range | Добавлен Range, проверен preflight |
| Comparator | Подбор сохранённого продукта не учитывал FOV, пустую/повторную пару и направление разности | Проверяются эти параметры; нельзя показать продукт другой конфигурации |
| Диагностика | Широкие live-запросы могли истекать по таймауту | Выбор детектора и небольшого радиуса в verifier; таймаут нового окружения 120 с; bounded retry и лимит загрузки сохранены |

OpenAPI экспортирован; TypeScript-схема клиента перегенерирована. Настоящие FITS,
результаты проверки, кэши и `.env` исключены из коммита.

несогласованной по длине волны разности. Увеличение размера PNG не улучшает разрешение телескопа.
