# План развития и соответствие задаче

Приоритет — удобное сравнение повторных наблюдений и честное отображение происхождения данных.
Таблица отражает бэкенд и интерфейс Mission Control; научные ограничения сохраняются.

| Возможность из задачи | Сейчас | Следующий шаг |
| --- | --- | --- |
| Поддерживать новые релизы | Настраиваемые коллекции, TTL кэша | Автоматическая проверка доступных коллекций и правил дедупликации |
| Показывать 102 спектральных канала | Диапазоны детекторов, справочная 102-bin линейка и явно обозначенные модели в UI | Выбор спектрального канала по реальной калибровке, HiPS/cube обзор |
| Сложение данных | Взвешенное среднее внутри детектора | Спектральное согласование, clipping, контроль PSF |
| Сравнение эпох | Difference/blink на общей WCS-сетке, split wipe и FITS-инспектор в UI | Группировка посещений, согласование длин волн и PSF |
| Выбор поля зрения | Радиус поиска и сторона выходного поля | Оценка объёма/времени, мозаика нескольких снимков |
| Gaia / WISE | Не реализовано | Каталожные адаптеры, координатная эпоха, proper motion, ссылки CDS |
| Координаты в URL | RA/Dec/цель, режим, FOV, радиус, источник и детектор | Сохранение времени и остальных параметров задачи в URL |
| Метаданные загрязнения | FLAGS в FITS, маскирование, provenance | Расшифровка битов, статистика и визуальный слой на фронтенде |
| Спектры на лету | Не реализовано | CWAVE/CBAND, апертурная/PSF-фотометрия, неопределённости и флаги |
| Движущиеся объекты | Визуальное сравнение и синтетический пример | Поиск кандидатов, треки, исключение артефактов и известных объектов |

## Ближайшие этапы

NEOSSat/CADC уже подключён для публичных COR/CORD: поиск, WCS cutout и blink.
Ограничения: nearest-neighbour preview в counts, без новой астрометрической привязки,
дисперсий, масок качества и фотометрической нормировки. Stack/difference этой миссии
пока отключены. Альтернативные каталоги CSA ASTRO/XML не скачиваются целиком.

1. Провести визуальную проверку Mission Control в браузерах и на мобильных устройствах;
   автоматические проверки навигации, поиска, таймлайна и очереди уже реализованы.
2. Проверить пять обязательных полей из `/api/v1/targets` через `scripts/verify_targets.py`,
   затем визуально идентифицировать объекты вместе с исследователем. Создание blink не
   подтверждает движение: нужно исключить влияние длины волны, масок, PSF и эпохи координат.
3. Добавить просмотр FLAGS и качество кадров, группировку по посещениям и более узкий выбор волн.
4. Реализовать калиброванные спектральные измерения и Gaia DR3/WISE overlays.
5. Подготовить публичное размещение с квотами, очисткой данных, мониторингом и проверкой нагрузки.

Простой difference не является алгоритмом открытия планеты. Все автоматические кандидаты
в будущих версиях должны сопровождаться метаданными, оценкой неопределённости и проверкой.

## Проверка интеграции IDKWht2do — 15 ноября 2026

Добавлены выбор детектора в архивном запросе, временные ограничения в Live Explorer,
сохранение контекста при навигации, защита от позднего опроса старой задачи и live-проверка
спектральной WCS исходного MEF (без SIP только для альтернативной WCS W).
Это исправления интеграции и диагностики, без добавления калиброванной фотометрии,
измеренных спектров или согласованных по длине волны разностей.
Проверка UI и реального API/worker описана в [отчёте](repair-audit-2026-11-15.md).
