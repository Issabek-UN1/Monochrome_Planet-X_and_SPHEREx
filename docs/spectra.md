# Измеренный спектральный профиль DR1

Spectral Lab получает реальные значения DR1 All-Sky FITS Cube: 102 номинальных
слоя с длинами волн из SPECTRAL_CHANNELS. Каналы 51 и 52 в текущем DR1 пусты.
[Описание продукта IRSA](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/overview_dr1.html).

Откройте Spectral Lab, проверьте RA/Dec и нажмите **LOAD MEASURED DR1 SPECTRUM**.
Нужны API и worker с `SPHEREX_PROVIDER=irsa`. Модели и приблизительные молекулярные
маркеры находятся в отдельном сворачиваемом справочном блоке.

## API

Отправьте `POST /api/v1/jobs` с телом:

```json
{
  "kind": "spectrum",
  "source": "spherex",
  "observation_ids": [],
  "ra": 133.79512916666667,
  "dec": -7.245147222222222,
  "subtract_zodi": false
}
```

Опросите обычный `GET /api/v1/jobs/{id}`. После succeeded получите
`GET /api/v1/jobs/{id}/spectrum` либо артефакты spectrum.json, spectrum.csv и provenance.json.
Ответ содержит координаты запроса и выбранного пикселя, URL/релиз/ETag куба,
маску отклонения, объём загрузки и массив из 102 каналов. У каждого канала есть
номер, детектор, подканал, длина волны, MJy/sr, NHITS, FLAGS, usable и причина исключения.
Отрицательные значения сохраняются. Пустые CSV-значения и uncertainty=null не означают ноль.

## Метод и ограничения

Извлекается поверхностная яркость ближайшего пикселя мозаики с архивной WCS.
График использует физические значения MJy/sr без нормализации. ZODI уже вычтен
архивом; повторного вычитания нет. Пустые/отклонённые каналы не интерполируются.
Значения отклонённых каналов остаются в таблице качества и экспорте.

Это **не апертурная или PSF-фотометрия именованного источника**. Пиксель включает
фон и соседей; координаты не переносятся по собственному движению. В кубе нет
VARIANCE: ошибки неизвестны. Возможны артефакты мозаики, изменения PSF и смешение эпох.
Атмосферная классификация и обнаружение молекул не выполняются. Для исследовательской
фотометрии используйте Spectrophotometry Tool, как рекомендует
[официальный пример IRSA](https://caltech-ipac.github.io/irsa-tutorials/spherex-hipscube/).

## Транспорт и хранение

Фиксирован снимок hips_20261026, HEALPix order 5 NESTED. Через HTTPS Range запрашиваются
только заголовки, таблицы и нужный пиксель IMAGE/NHITS/FLAGS во всех слоях. Проверяются
206/Content-Range, длина, размер и ETag. Редиректы и полный download fallback запрещены.
До шести одновременных запросов, один повтор временной ошибки, deadline 300 с.
Временный частичный FITS имеет размер до 384 MiB и удаляется после извлечения;
он никогда не выдаётся как результат. JSON/CSV сохраняются в каталоге задачи.
Demo-режим такую задачу отклоняет; ошибка архива остаётся ошибкой.

## Проверка 15 ноября 2026

Offline проверено равенство Range-выборки исходному FITS, табличные волны, отрицательные
значения, NaN/нулевой NHITS, unsigned FLAGS/BZERO, отсутствие выдуманных ошибок,
очередь, типизированный API, артефакты и удаление временного файла.

Реальный браузер → API → worker для WISE 0855: **102 слоя, 100 usable, пустые 51/52**.
Загружено 68 664 байта; график и JSON/CSV доступны. Проверены 1440/390 px без
горизонтального переполнения и ошибок JavaScript. Это проверка извлечения в заданной
точке, без утверждения об идентификации или качестве фотометрии самого WISE 0855.
